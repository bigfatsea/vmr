📖 Agent 配置指南

下面的每个指南展示了如何把某个 AI 编程 Agent 配置为指向本 VMR 实例。 始终需要三个核心值：Base URL（见上方）、API 密钥（向管理员索取）、 以及一个 虚拟模型名（即上面列出的模型之一）。 若 Agent 支持，还可进一步配置上下文窗口（如 200k）、思考/推理深度（如 high、budget_tokens）以及视觉多模态能力（image），以完全释放 VMR 上游端点的全量能力。 大多数 Agent 支持 OpenAI Chat Completions 协议或 Anthropic Messages 协议 — 选择与你所用 Agent 原生 API 匹配的协议分区。

Anthropic Messages 协议 Anthropic Messages

原生使用 Anthropic Messages API 的 Agent。将 Base URL 指向 VMR 的 Anthropic 兼容端点。API 密钥通过 x-api-key 请求头发送。

Claude Code

Anthropic Messages 环境变量 / settings.json thinking & effort

Anthropic 官方的终端编程 Agent。可通过环境变量或 ~/.claude/settings.json 路由到 VMR。 Claude Code 会自动连接 ANTHROPIC_BASE_URL。 可通过 MAX_THINKING_TOKENS（固定 Token 数）或 CLAUDE_CODE_EFFORT_LEVEL / /effort（自适应思考）调节推理深度。 官方文档 →

📄 ~/.bashrc、~/.zshrc，或 ~/.claude/settings.json
Shell（环境变量） 
# 方案 1：Shell 环境变量
export ANTHROPIC_BASE_URL={{BASE_URL_ANTHROPIC}}
export ANTHROPIC_AUTH_TOKEN=YOUR_VMR_API_KEY
export ANTHROPIC_MODEL=claude

# 思考深度：Token 预算（如 8192，0 为禁用）或自适应级别（low, medium, high, max）
export MAX_THINKING_TOKENS=32768
export CLAUDE_CODE_EFFORT_LEVEL=high
JSON (~/.claude/settings.json) 
{
  "env": {
    "ANTHROPIC_BASE_URL": "{{BASE_URL_ANTHROPIC}}",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_VMR_API_KEY",
    "MAX_THINKING_TOKENS": "32768"
  },
  "model": "claude"
}

OpenAI Completions 协议 OpenAI Completions

原生使用 OpenAI Chat Completions API 的 Agent。将 Base URL 指向 VMR 的 OpenAI 兼容端点。API 密钥通过 Authorization: Bearer 请求头发送。

Pi Agent

OpenAI Completions Anthropic Messages models.json context window vision & reasoning

Pi 是一个极简、可扩展的终端 AI 编程 Agent（earendil-works/pi-mono）。 将 VMR 作为自定义提供方加入 ~/.pi/agent/models.json，并显式声明 contextWindow、maxTokens、input（多模态能力）和 reasoning。 Pi 按 API 协议区分提供方，因此 VMR 会以 vmr-openai 和 / 或 vmr-anthropic 出现——openai-completions 与 anthropic-messages 均支持。 官方文档 →

📄 ~/.pi/agent/models.json（如果不存在则创建）
JSON (~/.pi/agent/models.json) 
{
  "providers": {
    "vmr": {
      "baseUrl": "{{BASE_URL_OPENAI}}",
      "api": "openai-completions",
      "apiKey": "YOUR_VMR_API_KEY",
      "models": [
        {
          "id": "coding",
          "name": "Coding (VMR)",
          "contextWindow": 200000,
          "maxTokens": 65536,
          "input": ["text", "image"],
          "reasoning": false
        },
        {
          "id": "agent",
          "name": "Agent Reasoning (VMR)",
          "contextWindow": 200000,
          "maxTokens": 65536,
          "input": ["text", "image"],
          "reasoning": true
        }
      ]
    }
  }
}

Codex CLI

OpenAI Completions 环境变量 / config.toml context & reasoning

OpenAI 官方的终端编程 Agent。可通过环境变量或 ~/.codex/config.toml 路由到 VMR。 支持在 config.toml 中配置 model_reasoning_effort（minimal / low / medium / high / xhigh）与 model_context_window 来管理模型上下文和推理深度。 官方文档 →

📄 ~/.bashrc、~/.zshrc，或 ~/.codex/config.toml
Shell（环境变量） 
# 方案 1：环境变量
export OPENAI_BASE_URL={{BASE_URL_OPENAI}}
export OPENAI_API_KEY=YOUR_VMR_API_KEY
TOML (~/.codex/config.toml) 
# 默认模型与推理深度
model = "coding"
model_reasoning_effort = "high"
model_context_window = 200000
model_auto_compact_token_limit = 180000

# VMR 自定义提供方
[model_providers.vmr]
name = "VMR"
base_url = "{{BASE_URL_OPENAI}}"
env_key = "OPENAI_API_KEY"
wire_api = "responses"

Cline & Roo Code

OpenAI Completions Anthropic Messages 界面配置 context window vision & tools

VS Code / VSCodium 上的自主 AI 编程扩展插件。在插件设置（⚙️）中选择 OpenAI Compatible（或 Anthropic Compatible）， 然后填入 Base URL、API 密钥、模型名、上下文窗口及多模态视觉开关。 Cline 文档 → · Roo Code 文档 →

⚙️ VS Code 插件设置面板
配置参数（OpenAI Compatible） 
# Cline / Roo Code 设置面板:
API Provider: OpenAI Compatible
Base URL: {{BASE_URL_OPENAI}}
API Key: YOUR_VMR_API_KEY
Model ID: coding

# 高级模型设置 (Model Configuration):
Context Window: 200000
Max Output Tokens: 65536
Include Images: Enabled（支持图片/截图输入）
Native Tool Calling: Enabled

Aider

OpenAI Completions 环境变量 / conf.yml reasoning & metadata

终端里的 AI 结对编程工具。支持通过环境变量或 ~/.aider.conf.yml 将 LLM 请求路由到 VMR。 可结合 .aider.model.metadata.json 声明完整上下文长度与多模态视觉能力，并通过 --reasoning-effort 或 --thinking-tokens 调整思考深度。 官方文档 →

📄 ~/.bashrc、~/.zshrc、~/.aider.conf.yml，或 .aider.model.metadata.json
Shell（环境变量） 
# 方案 1：环境变量
export AIDER_OPENAI_API_BASE={{BASE_URL_OPENAI}}
export AIDER_OPENAI_API_KEY=YOUR_VMR_API_KEY
export AIDER_MODEL=openai/coding

# 可选：推理深度与思考预算
export AIDER_REASONING_EFFORT=high
export AIDER_THINKING_TOKENS=32768
YAML (~/.aider.conf.yml) 
openai-api-base: {{BASE_URL_OPENAI}}
openai-api-key: YOUR_VMR_API_KEY
model: openai/coding
edit-format: diff
weak-model: openai/coding
reasoning-effort: high
JSON (.aider.model.metadata.json - 上下文与视觉元数据) 
{
  "openai/coding": {
    "max_input_tokens": 200000,
    "max_output_tokens": 65536,
    "input_cost_per_token": 0,
    "output_cost_per_token": 0,
    "supports_images": true
  }
}

OpenCode

OpenAI Completions config context window vision & reasoning

一个基于终端的 AI 编程 Agent（opencode.ai）。 在 opencode.json 中配置自定义提供方，支持显式声明 limit（上下文与输出）、modalities（视觉）和 reasoning。 官方文档 →

📄 opencode.json（项目根目录）或 ~/.config/opencode/opencode.json
JSON (opencode.json) 
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "vmr": {
      "name": "VMR",
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "{{BASE_URL_OPENAI}}",
        "apiKey": "YOUR_VMR_API_KEY"
      },
      "models": {
        "coding": {
          "name": "Coding",
          "limit": {
            "context": 200000,
            "output": 65536
          },
          "modalities": {
            "input": ["text", "image"]
          },
          "reasoning": false
        },
        "agent": {
          "name": "Agent",
          "limit": {
            "context": 200000,
            "output": 65536
          },
          "modalities": {
            "input": ["text", "image"]
          },
          "reasoning": true
        }
      }
    }
  }
}

Continue.dev

OpenAI Completions config.yaml / json context length capabilities

一个面向 IDE（VS Code、JetBrains）的开源 AI 代码助手。在 ~/.continue/config.yaml（新版推荐格式）或 ~/.continue/config.json 中将 VMR 添加为模型提供方， 支持声明 contextLength、maxTokens 及模型能力 capabilities（工具调用、图片上传等）。 官方文档 →

📄 ~/.continue/config.yaml（推荐）或 ~/.continue/config.json
YAML (~/.continue/config.yaml - 现代标准格式) 
models:
  - name: VMR Coding
    provider: openai
    model: coding
    apiBase: {{BASE_URL_OPENAI}}
    apiKey: YOUR_VMR_API_KEY
    capabilities:
      - tool_use
      - image_input
    defaultCompletionOptions:
      contextLength: 200000
      maxTokens: 65536
      reasoningEffort: high
JSON (~/.continue/config.json - 兼容格式) 
{
  "models": [
    {
      "title": "VMR Coding",
      "provider": "openai",
      "model": "coding",
      "apiBase": "{{BASE_URL_OPENAI}}",
      "apiKey": "YOUR_VMR_API_KEY",
      "contextLength": 200000,
      "completionOptions": {
        "maxTokens": 65536
      },
      "capabilities": ["tools", "uploadImage"]
    }
  ]
}

Cursor (IDE 与终端 Agent)

OpenAI Completions ide settings / env var custom models

Cursor 支持在 IDE 设置中直接覆盖 OpenAI Base URL，或在终端使用 cursor-agent 将请求路由到自定义 OpenAI 兼容端点。 官方文档 →

⚙️ Cursor IDE 设置 或 终端 Shell（cursor-agent）
Cursor IDE 设置（界面操作） 
# 1. 打开 Cursor 设置 -> Models
# 2. 在 'OpenAI API Key' 处填写：
OpenAI API Key: YOUR_VMR_API_KEY

# 3. 开启 'Override OpenAI Base URL'，并填写：
OpenAI Base URL: {{BASE_URL_OPENAI}}

# 4. 在 'Model Names' 处点击 '+ Add Model'，添加虚拟模型名称：
Model: coding
# 5. 点击 'Verify' 验证连接是否成功
终端 CLI (cursor-agent) 
# 将 Cursor CLI agent 指向 VMR
export OPENAI_BASE_URL={{BASE_URL_OPENAI}}
export OPENAI_API_KEY=YOUR_VMR_API_KEY
export CURSOR_API_KEY=YOUR_VMR_API_KEY

OpenAI Responses 协议 OpenAI Responses

调用新一代 OpenAI Responses API（/v1/responses）的工具与 SDK。 将 Base URL 指向 VMR，并配合 openai-responses 协议的虚拟模型使用。

OpenAI Responses API (SDK 与工具)

OpenAI Responses python / curl / sdk responses api

连接使用 OpenAI /v1/responses 端点的应用与 SDK。 在 VMR 中配置为 openai-responses 协议的虚拟模型将自动处理下游请求分发与响应流转换。

📄 Python SDK / API 调用
Python (OpenAI SDK) 
from openai import OpenAI

client = OpenAI(
    base_url="{{BASE_URL_OPENAI}}",
    api_key="YOUR_VMR_API_KEY",
)

# 请求 POST {{BASE_URL_OPENAI}}/responses
response = client.responses.create(
    model="coding",
    input="分析并重构 internal/server/auth.go 中的鉴权中间件",
)
print(response.output_text)
