"≈ Tokens Wasted" is estimated via a ~4 bytes/token dense ASCII heuristic; exact values require pricing layer settlement. "Shipped" records schema bytes sent with payloads across requests; "Wasted" records schema bytes of tools never called. Low waste ratio indicates tight tool declaration; high ratio suggests declared tool surface is far larger than actual usage.
