## 1. AFP 定义

> Agent 燃料值（Agent Fuel Point，简称 AFP）是 Agent Plan 套餐的统一用量计费单位，用于量化智能体
> （Agent）资源的消耗。

AFP 是火山方舟 Agent Plan（个人版与企业版 Team 均适用）的唯一计量单位，覆盖文本生成、向量化、
视频生成、图片生成、语音、以及若干 Harness（专业数据集、豆包搜索、Agent 记忆、AI Native 应用
开发底座、Agent 进化）在内的全部套餐内资源消耗。

## 2. 抵扣公式（按业务类型）

单次请求的 AFP 消耗按业务类型分别计算：

| 业务类型 | 公式 |
|---|---|
| 文本生成模型、向量化模型 | `(输入 token × 输入抵扣系数 + 输出 token × 输出抵扣系数) / 10,000` |
| 视频生成模型 | `消耗的 token / 10,000 × 抵扣系数` |
| 图片生成模型 | `成功生成的图片张数 × 抵扣系数` |
| 语音模型 doubao-seed-tts-2.0 | `文本字符数 / 10,000 × 抵扣系数` |
| 语音模型 doubao-seed-asr-2.0 | `语音文件时长(小时) × 抵扣系数` |
| 专业数据集 | `调用次数 × 抵扣系数` |

原文注：视频生成预估消耗的 token 数另见「价格示例」文档（<https://www.volcengine.com/docs/82379/1544106#2653dbb3>）的 token 用量估算公式，本文未展开抓取该页。

## 3. 抵扣系数

### 3.1 文本生成模型与向量化模型

**模型决定模型抵扣系数，输入长度决定输入分段系数**：

```
输入抵扣系数 = 模型抵扣系数 × 输入分段系数
输出抵扣系数 = 模型抵扣系数（不受输入长度分段影响）
```

输入分段系数按**该次请求的输入 token 长度**取值：

| 输入长度 | 分段系数 |
|---|---|
| ≤ 32k | × 0.67 |
| 32k < 输入长度 ≤ 128k | × 1 |
| > 128k | × 2 |

模型抵扣系数（原文表格，"即将下线"标注原样保留）：

| 模型类别 | 模型 | 模型抵扣系数 |
|---|---|---|
| 文本生成（极速） | doubao-seed-2.0-mini | 0.25 |
| 文本生成（标准） | doubao-seed-2.0-lite | 0.5 |
| 文本生成（标准） | deepseek-v4-flash | 0.5 |
| 文本生成（进阶） | doubao-seed-2.1-turbo | 2.5 |
| 文本生成（进阶） | doubao-seed-evolving | 2.5 |
| 文本生成（进阶） | doubao-seed-2.0-code（即将下线） | 2.5 |
| 文本生成（进阶） | doubao-seed-2.0-pro（即将下线） | 2.5 |
| 文本生成（进阶） | minimax-m2.7（即将下线） | 2.5 |
| 文本生成（进阶） | minimax-m3 | 2.5 |
| 文本生成（进阶） | kimi-k2.6（即将下线） | 4.5 |
| 文本生成（进阶） | kimi-k2.7-code | 4.5 |

例：doubao-seed-2.1-turbo，输入长度 ≤32k 时，输入抵扣系数 = 2.5 × 0.67 = 1.675，输出抵扣系数恒为 2.5。

**限时活动**（原文摘录，2026年6月10日18:00:00至2026年11月8日23:59:59）：Auto 模式在 Agent Plan
中抵扣系数为 0.5，支持路由到 kimi-k3；夜间 00:00–8:00 期间 kimi-k3 的路由比例会大幅提升。详见
<https://www.volcengine.com/docs/82379/2533565>（未展开抓取）。

### 3.5 官方抵扣示例（原文摘录）

- 文本生成：doubao-seed-2.1-turbo，输入 50k token、输出 0.5k token →
  `(50000×2.5 + 500×2.5) / 10000 = 12.625 AFP`
- 视频生成：doubao-seedance-2.0-fast，输入含视频、消耗 150k token →
  `150000 / 10000 × 110 = 1650 AFP`
- 图片生成：doubao-seedream-5.0-lite，成功生成一张图片 → `99 AFP`
- 语音：doubao-seed-tts-2.0，文本 2000 字符 → `2000 / 10000 × 1350 = 270 AFP`
- 专业数据集：成功调用一次中国金融数据库 → `12 AFP`

|---|---|---|---|---|

| 月额度（AFP） | 20,000 | 100,000 | 250,000 | 500,000 |
| 周额度（AFP） | 7,000 | 35,000 | 87,500 | 175,000 |

原文注：企业版价格与月额度未与个人版严格保持等比（企业版单价更高、含更多模型/Harness 权益），
两者是不同的产品线，不可直接换算。视觉模型日额度表格原文渲染存在合并单元格，未能可靠拆分到每一档，故本文不收录企业版该项数值。

### 4.3 额度刷新规则（个人版、企业版一致）

| 窗口 | 刷新规则 |
|---|---|
| 5 小时限额 | 根据首次请求发生时间，以 5 小时为周期定时刷新 |
| 周限额 | 每周一 00:00:00 重置 |
| 日限额 | 每日 00:00:00 重置（仅限视觉模型） |
| 月限额 | 每订阅月第 1 日 00:00:00 重置 |

套餐有效期以自然月为单位，自购买成功当日开始计算（示例：01.31 订购成功，02.28 23:59 到期，非闰年）。

## 5. 超额后付费

未开启超额后付费时，套餐额度在周期内耗尽后需等待下一周期自动恢复，不消耗其他资源包或账户余额。

开启后：套餐周期内额度未用尽时优先抵扣套餐额度；额度用尽后自动切换至超额后付费模式（无需修改
Base URL / API Key / 模型名），按对应模型的「后付费单价」计费；周期额度刷新后自动切回套餐内抵扣。

文本生成模型、向量化模型：触达 5 小时/周/月任一限额即切换。语音模型、Harness：无 5 小时/周限额，
仅在触达月限额时切换。`auto` 模式不支持超额后付费。

支持/不支持开启超额后付费的模型（原文摘录）：

| 模型 | 支持超额后付费 |
|---|---|
| doubao-seed-2.0-mini / -2.0-lite / deepseek-v4-flash / doubao-seed-2.1-turbo / doubao-seed-evolving / doubao-seed-2.0-code / doubao-seed-2.0-pro / glm-5.2 / deepseek-v4-pro / doubao-embedding-vision | 是 |
| minimax-m2.7 / minimax-m3 / kimi-k2.6 / kimi-k3 / 全部图片与视频生成模型 | 否 |
| doubao-seed-tts-2.0 | 是，3 元/万字符 |
| doubao-seed-asr-2.0 | 是，1 元/小时 |

Harness 超额后付费：专业数据集 0.024～0.048 元/次（按数据类型）；豆包搜索 0.020 元/次；Agent
记忆、AI Native 应用开发底座支持；Agent 进化不支持。

## 6. 套餐管理规则（个人版，原文摘录）

- **升配**：套餐有效期不变，补齐差价即可升配（`差价 = (升配套餐月价 − 原套餐月价) / 30 × 剩余天数`）；
  仅支持升配、不支持降配。升配后当月月额度 = 升配套餐月额度 × 当月剩余时长占比 + 原套餐月额度 ×
  当月已用时长占比；5 小时/周限额升配后直接变为新套餐对应值；当月已用额度不清零。
- **续费**：支持自动续费（连续包月）与手动续费；单次下单不超过 12 个月，存量 + 新购不超过 24 个月。
- **退订**：支持非七天无理由自助退订，具体退款公式见通用退订说明页（未展开抓取）。
- **额度使用限制**：同一订阅套餐可在所有支持的 AI 工具中使用、额度共享；文本生成模型及向量化
  模型不可用于常规 API 调用场景之外的用途，非 AI 工具场景下使用可能被判定为滥用。

（企业版另有席位管理、权限管理等企业专属规则，见 §4.2 引用的原始文档，本文不展开。）
