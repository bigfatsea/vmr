## 技术准确性检查清单

每篇文章发布前，逐条核对：

- [ ] 软屏蔽检测：说的是 `input_sensitive`/`output_sensitive` JSON 字段标记，**不是**文本模式匹配
- [ ] 软屏蔽检测：明确标注"当前为观测模式，不自动 failover"
- [ ] Context Length Exceeded：**不声称已实现 failover**——这是 P1 特性，尚未落地
- [ ] 错误分类：使用准确的 ErrorClass 名称（ErrAuth/ErrRateLimit/ErrEndpoint/ErrTransient/ErrContent/ErrClient）
- [ ] 审计记录格式：`soft_block_detected` 在 `norm` 数组里，不是顶层字段
- [ ] thinking 剥离：准确描述 ` thinking... response` XML 标签剥离 + "Thinking Process:" 草稿剥离两种模式
- [ ] 恢复探测：准确描述为独立后台探测（不占用真实请求）——`probe_mode: passive`（单飞探针）已于 2026-08-02 移除，文章不应再提及
- [ ] 竞品对比：不声称 CCR "没有日志"——它有，只是元数据级
- [ ] 安装指令：全部使用 `brew install` 或直接下载二进制方式
- [ ] 项目定位：个人工具，MIT 开源，不 SaaS 化，不卖企业版
