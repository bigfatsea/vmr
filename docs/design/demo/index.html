VMR Console — Unified Design Demo

Static mock pages for the console-unification proposal. Pure HTML/CSS/JS, no server, no network — mock data only.

Overview

Status + Stats merged into one flat page — vitals, quota, topology, live requests, recent failures, performance, traffic. No tabs; the header section rail is the table of contents.

Log

Full-bleed terminal. Mock streaming with level + substring filters, pause/resume, auto-scroll handoff, and a simulated disconnect after ~45s.

Help

Agent configuration guides as accordions with copy-to-clipboard snippets and a shared-key connection check.

Demo interactions worth trying
  • Overview: use the header section rail to jump between blocks; click the countdown to refresh the whole page at once (pausing turns the countdown itself amber); hover the chart for the per-bucket breakdown (red dots mark buckets with errors); switch the Performance window — the whole row moves together, and rows with no traffic in that window fall back to no samples; read Recent Failures for the "why did that one fail" gap between Live and the hourly aggregates; ⚡ Inject stall and ⛔ Inject queue backlog for the two incident shapes; 🚫 Simulate 401 then Connect for the unified 401 flow.
  • Log: toggle the level chips, type a substring (hits are highlighted), scroll up to pause autoscroll ("↓ N new" chip), ⌘P to pause the stream, wait ~45s for the disconnect banner, then Reconnect.
  • Help: copy a snippet or the base URL, store a key — then check any other page's header: the key is shared via localStorage across all pages.
  • Right-bottom demo panel (Overview) and the DEMO · mock data ribbon exist only in the demo, not in the real design.
