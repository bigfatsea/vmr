Demo interactions worth trying
  • Overview: switch tabs (URL hash remembers), watch the Live table fill up, press ⚡ Inject stall for the red stall badge, 🚫 Simulate 401 then Connect to see the unified 401 flow, copy a Connect URL.
  • Log: scroll up to pause autoscroll ("↓ N new" chip), type a substring to filter, wait ~45s for the disconnect, then Retry.
  • Help: copy a snippet, store a key — then check the Overview header badge: the key is shared via localStorage across all pages.
  • Right-bottom demo panel (Overview) and the DEMO · mock data ribbon exist only in the demo, not in the real design.
