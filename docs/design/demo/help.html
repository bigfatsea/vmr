Agent Configuration Guides

Point any AI coding agent at this VMR instance: the base URL below plus a virtual model name is all most clients need. The API key is provisioned by your administrator (api_keys: in config.yaml) — it is never shown on this page.

Environment variables (add to your shell profile or launch wrapper):

export ANTHROPIC_BASE_URL=http://127.0.0.1:8800
export ANTHROPIC_AUTH_TOKEN=sk-your-vmr-key
export ANTHROPIC_MODEL=vm:agent
# per-call override:
# claude --model vm:cheap

Then export VMR_API_KEY=sk-your-vmr-key before launching.

Generic OpenAI SDK openai-completions 
from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:8800/v1",
    api_key="sk-your-vmr-key",
)
resp = client.chat.completions.create(
    model="vm:cheap",
    messages=[{"role": "user", "content": "hi"}],
)
Troubleshooting

• 401 from every request → the key in Authorization: Bearer must match an entry of api_keys:.

• Unknown model → virtual models are per-protocol; check the Overview page's topology.

• Live 401s mid-session → vmr was reloaded with a changed api_keys:; re-set the key (🔑 button, stored in this browser only).

• Request feels slow → check the Overview vitals (cooldowns) and Live tab (stall badges) first.
